# Agentic commerce

**[Open the briefing →](https://james-bonaguro.github.io/agentic-commerce/)**

A standing data briefing on agentic commerce: how much transaction value moves
through AI agents buying on someone's behalf, how fast that is growing, and what
changes structurally as it does. Written for a general audience, not for people
who work in tech. Every figure is a third-party forecast, shown as a range and
attributed on the page.

## Viewing it

- **Live:** https://james-bonaguro.github.io/agentic-commerce/
- **Offline:** download `index.html` and open it in any browser. No build step, no
  dependencies, no network calls, so it works off a laptop with the wifi off.
- **PDF:** open it and print. Print styles are maintained.

## Editing it

Everything is one file, `index.html`. All content lives in a single `D` object at
the top of the `<script>` tag and is rendered from there by plain JS. Nothing is
hardcoded in the markup, so copy and data changes happen in `D`.
